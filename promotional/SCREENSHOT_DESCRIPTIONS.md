# Screenshot Descriptions and Guidelines

This document provides detailed descriptions for each screenshot needed for the Chrome Web Store listing.

## Required Screenshots

Chrome Web Store requires **1-5 screenshots** at either **1280x800** or **640x400** pixels.

---

Demonstrates the green indicator state, showing the user has used less Claude than expected for the current time of day.

- Clean integration with Claude.ai's UI

## Screenshot Creation Tips

### General Guidelines
1. Use a clean browser window (no distracting tabs or bookmarks)
2. Use incognito mode to avoid personal information in screenshots
3. Ensure high resolution and clarity
4. Crop to exactly 1280x800 or 640x400 pixels
5. Use consistent styling across all screenshots

### Tools for Screenshots
- Chrome DevTools Device Mode for consistent sizing
- macOS Screenshot (Cmd+Shift+4) or Snipping Tool (Windows)
- Browser extensions like Awesome Screenshot
- Post-processing with image editors for cropping

### Privacy Considerations
- Blur or use fake data for any personal information
- Don't show real usage statistics if sensitive
- Use test/demo account if available
