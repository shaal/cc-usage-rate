## Detailed Description (4000 characters max)

### Description

Track your Claude.ai usage efficiency with beautiful, intuitive visual indicators!

**Claude Usage Tracker** adds helpful visual feedback to your Claude.ai usage settings page, showing you at a glance whether you're pacing your Claude usage optimally.

**Key Features:**

**Color-Coded Indicators**
- Green: You're ahead of schedule - room to use more Claude!
- Yellow: On track - your usage is perfectly paced
- Red: Usage is above expected - consider pacing yourself

**Smart Efficiency Tracking**
The extension calculates your usage efficiency delta, showing you a percentage that indicates how your actual usage compares to expected usage for the current time of day.

**Non-Intrusive Design**
- Only activates on your Claude.ai usage settings page
- Matches Claude.ai's clean, modern aesthetic
- Supports both light and dark modes
- No popups, no distractions

**Privacy First**
- All processing happens locally in your browser
- No data collection whatsoever
- No analytics or tracking
- No external server communication

**How It Works:**
1. Install the extension
2. Visit your Claude.ai usage settings page
3. See your usage efficiency at a glance with our circular indicators

**Perfect For:**
- Claude Pro and Team subscribers
- Users who want to maximize their usage allowance
- Anyone who likes to track their AI assistant usage

**Technical Details:**
- Lightweight and fast
- Built with modern web technologies
- Manifest V3 compliant
- Regular updates for compatibility

**Support:**
Found a bug or have a suggestion? We'd love to hear from you! Visit our GitHub repository to submit issues or contribute.
